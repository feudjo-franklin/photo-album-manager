# Photo Album Manager - Fullstack Application

A client-server application to manage photo albums.

## Tech Stack
- **Frontend**: React, Material UI
- **Backend**: Java 17, Spring Boot 3, JPA
- **Database**: MySQL 8
- **DevOps**: Docker, Docker Compose, Nginx
